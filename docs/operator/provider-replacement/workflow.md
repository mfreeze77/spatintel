# Provider replacement: workflow

The public contract for this component is provider-independent. Before replacement, export immutable configuration, identifiers, open data, provenance, policy, and integrity manifests. Import into the replacement adapter in quarantine, validate hashes and semantic identity, rehearse rollback, and publish only after review. Provider-specific credentials and opaque internal identifiers are not portable authority.

Progress 09 supplies a structural reference only; executable vendor migration remains external validation.
