# Reviewing Spatial Changes

A saved SIP view remembers the scene revision, camera, visible layers, clipping, selected objects, timeline, filters, redaction, and accessibility settings. It does not save reusable access tokens. Opening it again rechecks your current permissions.

Change candidates are proposals. Missing coverage is not treated as removal, and lighting, exposure, level-of-detail, or moving-person differences are separated from physical changes. An independent reviewer must accept a candidate before SIP can create a semantic change event, and a separate controlled commit records that accepted change in scene history.

Metric, visual, design, interaction, and evidence layers remain distinct. Picking an interaction proxy never creates a verified measurement by itself.
