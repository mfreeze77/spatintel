# Contracts, Events, and Migrations

## Contract sources

Canonical schemas live in `schemas/`:

- `schemas/openapi/` — service HTTP contracts;
- `schemas/jsonschema/` — persisted and exchanged document contracts;
- `schemas/events/` — versioned event registry;
- `schemas/protobuf/` — worker and operation control protocols;
- `schemas/sql/` — portable SQL references where applicable.

Generated language bindings live in `packages/contracts/{python,swift,typescript}`. Generate them with:

```bash
PYTHONPATH=src:. python -m tools.schema_codegen.generate --root .
```

CI uses `--check` and fails when generated bytes differ.

## Compatibility rules

- Existing required fields are not removed from a released major contract.
- Protobuf field numbers are never reused.
- Event names and schema versions remain addressable for replay.
- New readers accept supported prior versions or emit a stable incompatibility code.
- Future-schema capture packages are rejected safely and leave source bytes unmodified.
- Provider-specific extensions stay inside an adapter namespace.

## Operation and worker boundary

Large geometry and media bytes do not travel in control messages. Protocol records carry immutable asset references, hashes, coordinate-frame identifiers, bounded progress, and receipts. The object store remains the data plane.

The immutable operation request is the idempotency anchor. Retries reuse it; they do not create competing publication transactions.

## Database migrations

Alembic migrations are under `migrations/versions/`, with their immutable byte inventory in `migrations/manifest.json`.

Required rehearsal paths:

1. clean install to `head`;
2. upgrade from the prior release baseline;
3. preservation of immutable asset IDs and hashes;
4. backup before destructive changes;
5. denied destructive downgrade by default;
6. explicit isolated downgrade rehearsal;
7. restore and integrity verification.

SQLite exercises deterministic local behavior; PostgreSQL/PostGIS migration evidence is separately required for release.
