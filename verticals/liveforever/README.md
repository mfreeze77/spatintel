# LiveForever Vertical

This vertical composes SIP's evidence, timeline, scene, relationship, media, consent, audience-policy, generated-content lineage, export, and safety controls for preservation of people, places, stories, and memories.

Direct records, recollections, corroborated assertions, inference, generated reconstruction, conflict, and historical fact remain distinct. Voice, likeness, dialogue, and first-person simulation remain disabled unless explicit purpose-specific consent and safety gates pass.

## Entry points

- Domain implementation: `src/sip/liveforever.py`
- HTTP surface: `src/sip/api.py`
- User guide: `docs/user/LIVEFOREVER.md`
- Deterministic demonstration: `make demo-liveforever`
- Synthetic corpus: `tests/fixtures/liveforever/conflicting-recollections.json`
- Policy implementation: `src/sip/policy.py`

The manifest in this directory records required safeguards and preservation behavior.
