# Specification Changelog

## 1.1.0 — 2026-07-27

- Added a fourth coordinated representation: a disposable, non-authoritative interaction layer registered with metric, visual, and evidence layers.
- Added hybrid scene services, trust boundaries, provider registry, quarantine, validation, publication, and runtime architecture.
- Added splat-to-surface provider contracts covering local, private, external API, manual external, and research-shadow execution.
- Added bidirectional mesh-to-splat and splat-to-mesh derivation rules, support maps, LOD/tiling, cleanup/edit journals, protected geometry, and privacy editing.
- Added explicit asset roles, authority classes, use-specific suitability, collision/navigation profiles, loss declarations, and export sidecars.
- Added native splat-plus-mesh runtime behavior for picking, measurement re-resolution, collision, locomotion, clipping, occlusion, spatial audio, accessibility, and fallback.
- Added Construction and LiveForever hybrid-representation requirements and end-to-end pilot scenarios.
- Added external spatial-provider governance; SplatEdit remains a synthetic/public-data manual experiment until official commercial, privacy, automation, and deployment evidence is approved.
- Added comparative benchmark/release gates for geometry, protected objects, collision, navigation, picking, runtime, truth labels, privacy, and portability.
- Added candidate audit for SplatTransform, Spark, Mesh2Splat, MILo, Fast-PGSR, Open3D, gsplat, and related research.
- Added v1.0-to-v1.1 migration rules, sequenced epics, requirement traceability, and validation.

## 1.0.0 — 2026-07-26

- Replaced the prior outline with a complete multi-document engineering baseline.
- Added source-neutral capture and a canonical package contract.
- Added first-party ARKit/LiDAR capture and Polycam raw-export ingestion lanes.
- Added LingBot-Map adapter design pinned to commit `1f480aeb8a47a24656090d46d053115b7fe60435` and explicit checkpoint-license gates.
- Added pose fusion, external loop closure, factor-graph optimization, TSDF, meshing, splats, uncertainty, and cross-session change detection.
- Added stable scene entities, evidence graph, provenance, Spatial Git, semantic diffs, and authority classes.
- Added complete Construction and LiveForever vertical specifications.
- Added privacy volumes, consent and family governance, sensitive-building controls, and generated-memory labels.
- Added APIs, event catalog, job orchestration, viewer, spatial agent tools, deployment profiles, cost model, testing, release gates, and implementation backlog.
