# SIP Desktop Review

This is a local-first deterministic review application core. It opens immutable content-addressed RGB, depth, trajectory, and geometry inputs; records point, line, plane, semantic, and image-to-scene correspondences; preserves undo/redo and branch history; exposes factor residuals, loop constraints, source weights, and regional uncertainty; and exports proposal-only bundles behind policy and license gates.

The reference local HTTP profile binds only to loopback and requires Host, Origin, JSON content type, and CSRF validation. It does not require a cloud login. Native desktop packaging, notarization, GPU-driver recovery, and operator usability validation remain external.
